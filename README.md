# NutriBot 🤖🍽️
Este é um chatbot para o Telegram que ajuda a seguir um plano alimentar com lembretes e sugestões de refeições.

## Como Usar
1. Inicie o bot no Telegram com `/start`
2. Receba sugestões de refeições com `/menu`
3. Configure lembretes automáticos com `/configurar`

## Instalação
1. Clone este repositório:
   ```sh
   git clone https://github.com/seuusuario/nutribot.git
   ```
2. Instale as dependências:
   ```sh
   pip install -r requirements.txt
   ```
3. Execute o bot:
   ```sh
   python nutribot.py
   ```

## Hospedagem no Render
1. Conecte o repositório ao [Render.com](https://render.com/)
2. Use o comando `worker: python nutribot.py` no Procfile
3. Faça o deploy e ative o bot
